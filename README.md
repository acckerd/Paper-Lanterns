# Промо-сайт фестиваля «Paper Lanterns»

Интерактивный одностраничный промо-сайт, созданный в рамках изучения продвинутых технологий верстки. 
Проект полностью адаптирован под различные типы устройств и оптимизирован для плавной работы интерфейса.

🔗 **[ПОСМОТРЕТЬ САЙТ ВЖИВУЮ] (https://acckerd.github.io/Paper-Lanterns/)**

## 🛠️ Стек технологий и особенности архитектуры:
* **HTML5 / Семантика:** Валидная разметка с четким разделением на смысловые секции.
* **Sass (Indented) / БЭМ:** Код стилей структурирован по методологии БЭМ, что исключает конфликты классов.
* **Дизайн-система на CSS-переменных:** Все цвета, шрифты и базовые размеры вынесены в глобальный пульт управления (`:root`),
  а индивидуальные параметры анимации передаются динамически через HTML.
* **Advanced Анимации:** Реализована современная скролл-анимация (`Scroll-Driven Animations` через `animation-timeline: view()`).
* **Оптимизация на JavaScript:** Создан кастомный интерактивный курсор-звездочка. Движение оптимизировано через `requestAnimationFrame`.
* **Умный адаптив:** Кастомный курсор автоматически скрывается на сенсорных мобильных устройствах с помощью медиазапроса `@media (hover: hover)`.
